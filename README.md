# Java Spring Framework, Spring Boot & Spring AI – Generative AI

Welcome to my Java learning repository!

This repository contains practical exercises, code examples, and projects completed as part of my Udemy course **Java Spring Framework, Spring Boot, Spring AI – Gen AI**.

- Apply the concepts learned through practical coding exercises.
